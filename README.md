# mehrabi4.github.io

A deliberately minimal personal learning site.

The homepage has two parts: a left-hand **learning stuff** menu and a single featured artwork. Learning entries are added directly to the list in [`index.html`](./index.html), with topic pages stored under `learning/`.

## Preview

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
