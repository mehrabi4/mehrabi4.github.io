01

bytes

Very simple: 8 bits make one byte. A byte can be represented in different ways: as an integer from 0 to 255, in hexadecimal such as 0x12, or in a Python bytes literal such as b' '.

In Python, bytes is a built-in type. A bytes object holds an immutable sequence of byte values. For example, b'x' contains one byte. That byte has the integer value 120, the hexadecimal value 0x78, and the bit pattern 01111000.

literalb'x'
integer120
hex0x78
bits01111000

02

utf-8

A Unicode scalar value can be represented by one to four bytes in UTF-8. UTF stands for Unicode Transformation Format, and the 8 refers to its 8-bit code units.

For example, a is represented by one byte with the hexadecimal value 0x61. The laughing emoji 😂 is represented by four bytes: 0xF0 0x9F 0x98 0x82. Here, each byte is written in hexadecimal.

a 1 byte 0x61
😂 4 bytes 0xF0 0x9F 0x98 0x82
